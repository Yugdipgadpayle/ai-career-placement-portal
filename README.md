# AI Career & Placement Portal

This project is a full-stack final-year project built step by step.

## Goal

The portal helps students prepare for placements using profile building, resume analysis, ATS scoring, job recommendations, job applications, and interview preparation.

## Tech Stack

- Frontend: HTML, CSS, JavaScript, React, React Router, Axios
- Backend: Python, FastAPI, SQLAlchemy, Alembic, PostgreSQL
- Authentication: JWT
- AI Features: Resume parsing, ATS score, job recommendation, interview question generator
- Deployment: Vercel, Render or Railway

## Learning Approach

This project is developed in small milestones. Each milestone focuses on one professional software engineering concept before adding code.

## Current Milestone

Lesson 1: Project planning, requirements, SDLC, tech stack, and Git setup.
