# AI Career & Placement Portal Requirements

## Project Objective

The AI Career & Placement Portal helps students prepare for placements by offering resume analysis, ATS scoring, job recommendations, interview questions, job applications, and placement tracking.

## User Roles

### Student

- Register and login
- Create and update profile
- Upload resume
- View jobs
- Apply for jobs
- View application status
- Get ATS score
- Get recommended jobs
- Generate interview questions

### Recruiter

- Register and login
- Create company profile
- Post jobs
- View applications
- Shortlist or reject candidates

### Admin

- Manage students
- Manage recruiters
- Approve job posts
- View placement analytics

## MVP Features

- Authentication
- Student profile
- Recruiter job posting
- Job listing
- Job application
- Basic ATS score
- Basic job recommendation

## Future Features

- Resume parsing
- AI interview question generator
- Email notifications
- Analytics dashboard
- Deployment
