# User Stories

1. As a student, I want to register so that I can create my placement profile.
2. As a student, I want to login so that I can access my dashboard securely.
3. As a student, I want to update my skills so that job recommendations are more accurate.
4. As a student, I want to upload my resume so that I can get resume feedback.
5. As a student, I want to see an ATS score so that I can improve my resume.
6. As a student, I want to view available jobs so that I can apply for suitable roles.
7. As a student, I want to track application status so that I know my placement progress.
8. As a recruiter, I want to post jobs so that students can apply.
9. As a recruiter, I want to view applicants so that I can shortlist candidates.
10. As an admin, I want to approve job posts so that only valid jobs appear on the portal.
11. As an admin, I want to view analytics so that I can track placement performance.
12. As a student, I want interview questions based on a job role so that I can prepare better.
